# Security policy

## Reporting a vulnerability

Please report security problems **privately**, never in a public issue:

1. On the affected repository, open the **Security** tab and choose **Report a vulnerability**
   (GitHub's private reporting). This is the preferred way.
2. Or email **info@kohasolutions.com** with "Security" in the subject.

Include what is affected, how to reproduce it, and the version you used. We acknowledge a report within 3 working
days, keep you informed while we fix it, and credit you in the release notes unless you ask us not to.

## Scope

These policies cover the code in the Koha Solutions repositories on GitHub. A vulnerability in **Koha itself** should
go to the Koha community's security process: https://koha-community.org/security/

## Supported versions

The latest release of each repository receives security fixes.
