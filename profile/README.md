## 👋 About Us

**Koha Solutions** is building **Modern Koha** — a scalable, AI-powered library technology platform that combines **Koha Cloud** with **artificial intelligence, RFID, robotics, and modern automation** to transform traditional libraries into intelligent, automated environments.

Our goal is to modernize Koha beyond traditional library management software by integrating emerging technologies directly into everyday library operations.

The platform is already **operating in production with 20+ libraries**, backed by **about three years** of development and operational experience. We are building on this foundation to expand Modern Koha to libraries and educational institutions globally.

## 🧰 Open-Source Tools for Koha

Free tools for anyone who runs Koha, built from the problems we solve for libraries every day. Each one is tested
on a real Koha before it is released, and its README shows the output it really gives.

| Tool | What it does | Status |
|---|---|---|
| **koha-api-client** | Call the Koha REST API from the command line or Python; the token is handled for you | In progress |
| **koha-opac-snippets** | Tested copy-paste `OPACUserCSS` / `OPACUserJS` customisations, with screenshots | Planned |
| **koha-install** | One command installs Koha on Ubuntu or Debian | Planned |
| **koha-health-check** | Diagnose a broken Koha server and get the fix for each problem | Planned |
| [**koha-sql-reports**](https://github.com/kohasolutions/koha-sql-reports) | 18 SQL reports, each run through Koha's own report engine; columns checked on Koha 23.11–26.05 | ✅ Released |
| **koha-backup** | Scheduled backups with a restore you have actually tested | Planned |
| **koha-notice-templates** | Clean, mobile-friendly overdue, hold and welcome notices | Planned |
| **koha-csv-to-marc** | Turn a spreadsheet of books into a file Koha imports | Planned |

Practical answers to everyday Koha questions: **[Koha knowledge base](https://kohasolutions.com/knowledge-base)**.

## 🚀 What We're Building

### 🤖 AI-Powered Library Tools

- **AI Cataloging** — faster, more accurate bibliographic records ([AI Cataloging Assistant](https://kohasolutions.com/koha-ai-cataloging))
- **Dewey Decimal Classification (DDC)** — automated subject classification
- **Intelligent Search & Voice Search** — find resources naturally
- **Recommendations** — personalized discovery for patrons
- **Library Assistants** — AI help for staff and users
- **Data Analysis** — actionable insights from library data
- **Workflow Automation** — less manual work, more impact

### 📡 RFID Integration

Automating identification, circulation, inventory management, tracking, and self-service workflows. → [RFID Integration](https://kohasolutions.com/koha-rfid)

### 🦾 Robotic Automation

Extending automation into the physical library: automated book sorting, transportation, shelving, and other physical workflows.

### ☁️ Koha Cloud — [myopac.com](https://myopac.com)

Hosted, cloud-based Koha that lets libraries use a complete library system **without managing their own servers, updates, backups, security, hosting, or email infrastructure**.

| Capability | Description |
|---|---|
| ☁️ **Fully Hosted** | Secure, reliable cloud hosting managed by our team |
| 🌐 **Your Own Subdomain & OPAC** | A public catalog running the day you sign up |
| 📚 **MARC21 + Z39.50** | Cataloging with copy cataloging from external sources |
| 🔄 **Circulation & Reports** | Holds, fines, acquisitions, serials and reporting |
| 💾 **Automated Backups & Updates** | Always protected, always up to date |
| ✉️ **SMTP / Email Infrastructure** | Reliable library notices and communication |
| 🔔 **Firebase Notifications** | Real-time push notifications |
| 🔑 **Google Login** | Simple, secure authentication |
| 🛠️ **Technical Support** | The same team that runs the servers |
